# trusted-bank-rag
银行业监管制度与统计报表可信 RAG 问答系统：面向银行监管制度与统计报表问答场景，处理 500 余份不同格式文件、约 3000 条数据，设计可信 RAG 系统， 目标是在复杂监管文件与统计报表中实现可追溯、可核验、证据不足时不过度回答的问答能力。基于 LangGraph 编排整体工作流，形成文档解析 → 索引构建 → 混合检索 → Reranker → 证据筛选 → Jev/Gate 判断 → 答案生成 → 来源引用的完整链路，并针对表格、跨文件和条件型问题进行适配。建立独立评测与回归验证流程，在100 题 Blind Test 中最终达到 85%准确率；答案关联原始文件及页码， 支持人工核验与结果追溯。
