# 已知限制

- 多期、多操作数可能只找到部分依据；发现来源不保证找到精确条款或数值。
- 复杂条件、品种歧义与 UNKNOWN 状态仍可能产生错误判断。
- 长尾表格语义、层级和时间口径仍需验证；通用解析不是完美的业务事实数据库。
- 截断有有限重试，供应商 API 故障或模型变更仍可能影响交付。
- 默认 BM25 demo 没有覆盖混合检索及完整 LLM 性能。
- 私有数据和评测封装不公开，无法由本仓库完整复现私有 85% 结果。
- 依赖声明修正为本地实际 Haystack 版本，但全新隔离环境安装仍未验证。
- 公开代码沿用仓库所有者选择的 Unlicense，私有赛事资料未包含在发布范围内。
