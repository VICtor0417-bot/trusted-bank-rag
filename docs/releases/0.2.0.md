# 0.2.0 — 本地资料工作流与 Windows CPU 修复

本版本固定自有资料目录为 `raw/`、`data/generated/` 和 `results/`，提供 Windows CPU 兼容约束，并把检索初始化异常转换为 HTTP 503。

- README 包含安装、录入、入库、梗概、`.env`、完整功能开关、API/CLI、结果保存与排错。
- 新增 `python-dotenv[cli]` 依赖，支持文档中的配置加载命令。
- 新增初始化故障测试及 CPU 验证记录。
- 移除当前版本已跟踪的 Python 缓存和自动生成 demo 文件，本地文件保留，demo 仍可通过脚本生成。
- 不发布 Key、原始业务文件、私有知识库、模型权重、问答结果和 trace。

已有验证：35 项离线测试、依赖检查、缓存真实模型 hybrid 检索及一次授权的 DeepSeek 问答。该次 Jev 认证失败且数值校验 warning，不表示所有服务和答案质量均已通过验证。

升级后安装依赖并重启服务。已有 `.env` 不必覆盖，核对路径和开关即可。全新机器的完整安装与首次模型下载尚未验证。
